# Fastfony GitHub Organization 🚀

Welcome to **[Fastfony](https://fastfony.com/?source=github-org-readme)** — pragmatic Symfony, one bundle at a time.

---

## 🙋‍♀️ What is Fastfony?

Fastfony used to be a complete starter-kit. It's now **three open-source pieces**, all MIT:

- 📦 **Symfony bundles** — each does one thing well.
- 🎁 **Composer packs** — curated tooling, wired via Flex recipes.
- 🤖 **A Claude Code skill** — the expert that assembles your own starter-kit in one conversation with Claude.

Pick what you need. Skip the rest. [Read the manifesto →](https://fastfony.com/en/manifesto?source=github-org-readme)

**Tech baseline:** PHP 8.2+ (8.4+ for Symfony 8), Symfony 7.4 LTS or 8.0, AssetMapper (no Encore, no Node build step), Tailwind or Bootstrap, Doctrine ORM, Stimulus + Turbo.

## 📦 What's available today

### Bundles (MIT)

- [**fastfony/identity-bundle**](https://github.com/fastfony/identity-bundle) — Form login, magic login link, registration, password reset, users / roles / groups.

### Packs (MIT)

- [**fastfony/quality-pack**](https://github.com/fastfony/quality-pack) — PHPStan + PHP-CS-Fixer + Twig-CS-Fixer + GitHub Actions workflow + Makefile, in one `composer require --dev`.

### The Skill (MIT)

- [**fastfony/claude-skill**](https://github.com/fastfony/claude-skill) — bootstraps a full Symfony starter-kit (auth, Tailwind or Bootstrap, CI, quality) in one conversation with Claude. Free to use, fork, and improve.

More bundles coming — watch this organization.
